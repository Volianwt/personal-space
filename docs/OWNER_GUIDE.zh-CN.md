# 个人空间使用指南

## 今天

首页展示当天的问候、自己已有的记录和新闻。体重、日记和聊天数值从本机记录读取，第一次打开时为空，不会使用旧简历或历史对话里的健康数据填充。

新闻分世界、加拿大、科技，保留来源、原文链接和更新时间。完整服务启动后会按天更新，也可以点击手动刷新。拉取失败时保留上次缓存并注明；没有缓存时显示不可用。

## 放松一下

- **轻点气泡**：点击或触摸气泡，没有倒计时，点完可以重来。
- **方块亮起来**：点击一个格子会翻转它与上下左右的格子，让九个格子都亮起来。方向键移动焦点，空格或 Enter 操作。支持撤销、重开、提示和三关切换；使用提示不计最佳纪录。
- **呼吸一下**：开始后跟随圆圈，也可以按自己的舒适节奏。随时暂停或重新开始，离开标签页会暂停。系统开启“减少动态效果”时不播放缩放动画。

## 生活记录

选择日期后填写日记、心情、体重和食物。食物热量手动记录，不自动猜测份量或营养成分。填写后立刻尝试保存，顶部显示保存状态；如果保存失败，先导出数据再关闭页面。

侧栏可以搜索以前的日记。体重曲线使用最近 30 次实际测量，日期间距与真实时间一致。热量参考值由自己在设置里填写，可以留空。它只作为记录参照，不是营养建议。

生活记录页的 CSV 包含日期、体重、当天热量、心情和日记。删除整天记录前会要求确认。

## 聊一会儿

1. 在设置里选择 Ollama、LM Studio、OpenAI 或其他兼容服务。
2. 本地模式要先启动模型服务并下载/加载模型。网站本身不包含模型权重。
3. 点击“Fetch models”，选择适合聊天的模型。也可以手填模型 ID。
4. 云端模式填写自己的密钥。密钥只在本次页面打开期间保留，刷新后需要重新输入；长期使用可以在本机 `.env` 配置。
5. 新建对话，输入文字。Enter 发送，Shift+Enter 换行，中文输入法选字时不会直接发送。
6. 请求过程中可以停止等待。已发出的消息保留，网络恢复后可以重试。多段会话可从左侧切换。

助手只收到当前聊天记录与设置中的助手说明。日记、体重、食物记录和新闻不会自动附带。回复以纯文字显示，不执行代码或工具。API 选项会把聊天发送给所选服务商；不同服务的费用与数据政策以该服务为准。

较长会话超过本版本的请求上限时需要新建话题。完整记录仍留在本机，不会为了适配模型而静默删除旧消息。

## 更改风格和称呼

顶部月亮/太阳按钮切换昼夜主题，插图一起变化。设置里可以修改称呼和自设热量参考值。首页没有求职、学历或项目展示内容。

## 备份

右上角 Settings → Export full backup，保存 JSON 文件。导入时先验证格式，再确认替换当前记录。可先导出原有数据。

备份包含日记、心情、体重、食物、聊天和设置，不包含密钥、新闻缓存和小游戏最佳纪录。不同浏览器、不同网址不会自动同步。打开 `dist/preview.html` 与访问 `127.0.0.1:4278` 是两个数据空间；可以通过备份迁移。

## 常见问题

**看到“Offline mode”**：在项目目录运行 `npm start`，再打开命令输出的 HTTP 地址。直接打开 HTML 仅提供离线预览。

**新闻没有内容**：查看网络是否可用，尝试刷新或切换分类。服务不会编造头条代替真实内容。

**本地模型连接不上**：检查模型服务是否启动、端口是否与设置一致、模型是否已加载。Ollama 与 LM Studio 的接口格式不同，要选择对应选项。

**云端模型返回错误**：检查密钥、模型 ID、账户权限和额度。OpenAI 选项使用 Responses；兼容选项使用 Chat Completions。原生其他厂商 API 格式需要适配后才能使用。

**保存失败或找不到以前的记录**：检查是否更换浏览器/网址、是否使用隐私浏览、是否清除了站点数据。导出当前数据；有备份时可重新导入。没有云端自动恢复功能。
